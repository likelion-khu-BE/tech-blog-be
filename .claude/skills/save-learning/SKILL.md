# save-learning

Claude와 대화하다 배운 내용을 `learned/`에 저장하고 PR로 올리는 스킬.
목적: 팀원이 삽질로 얻은 지식을 프로젝트에 축적해 다음 사람이 같은 삽질을 반복하지 않게 한다.

## 언제 쓰나

팀원이 아래 중 하나를 말할 때:
- "이거 저장해줘", "배운 내용 저장", "learned에 추가해줘"
- "/save-learning"

---

## 흐름

### 1. 대화에서 핵심 추출

저장 전에 다음 세 가지를 파악한다. 불분명하면 팀원에게 한 번 물어보고 진행한다.

- **무엇을 배웠나**: 개념/원리/패턴
- **왜 이 대화에서 나왔나**: 버그, 질문, 코드 리뷰, 막힌 지점
- **이 프로젝트 어디에 연결되나**: 실제 코드/커밋/이슈

### 2. 문서 초안 생성

**필수 섹션 — 하나라도 빠지면 저장하지 않는다:**

```markdown
# {제목}

## 한 줄 요약
{이걸 모르면 어떤 버그/문제가 생기는가 — 1문장. "~에 대해 설명한다" 금지}

## 왜 알아야 하나
{모르면 실제로 어떤 일이 벌어지는지. "중요합니다" 같은 경고 문구 금지.
이 프로젝트에서 실제 발생한 버그/커밋이 있으면 여기서 연결한다.}

## 핵심 원리
{동작 원리를 기술적으로 정확하게.
추상적 비유보다 실제 메커니즘. 용어는 공식 용어 사용.
코드 예시 필수 — pseudocode 금지, 실제 Java/Spring 코드로.}

## 이 프로젝트 사례
{우리 코드에서 어디에 적용돼 있는지, 혹은 어디서 문제가 났는지.
파일 경로, 커밋 해시, 이슈 번호 포함.
연결할 사례가 없으면 섹션 통째로 생략.}

## 틀리기 쉬운 패턴
{같은 실수를 반복하게 만드는 패턴들.
형식: 틀린 코드 → 왜 틀렸나 → 올바른 코드.
최소 2개 이상.}

## 면접 포인트
{이 주제로 면접에서 나올 법한 질문 2~3개 + 핵심 답변.
답변은 "잘 모르겠습니다"가 나오지 않을 수준으로.}
```

**품질 기준:**
- 읽는 데 5분 안에 끝나야 한다 — 길이보다 밀도
- 코드는 복사하면 바로 동작하는 수준
- 파일명: `{주제-kebab-case}.md` (한글 가능)

### 3. 확인

전체 내용을 보여주고 한 번만 묻는다:

```
[저장할 내용 미리보기]
파일명: learned/{파일명}.md

{전체 MD 내용}

저장할까요? (y / 수정사항 말씀해주세요)
```

수정 요청 시 반영 후 재확인. y면 바로 실행.

### 4. 실행 (자동)

```bash
ORIGIN_BRANCH=$(git branch --show-current)

git fetch origin dev
git checkout -b learn/{slug} origin/dev

# 파일 두 개만 커밋
git add learned/{파일명}.md learned/INDEX.md
git commit -m "learn: {제목}"

# PR 오픈 (GH 인증은 세션 컨텍스트에서 찾아 쓴다)
gh pr create --base dev --title "learn: {제목}" --body "..."

git checkout $ORIGIN_BRANCH
```

**PR 본문 — 파일 안 열어도 핵심을 알 수 있는 수준으로 작성:**

```markdown
## 왜 이 주제를 정리했나

{계기 — 버그였으면 어떤 버그, 질문이었으면 어떤 상황. 1~2문장.}

## 이것만 알면 된다

- {핵심 포인트 1}
- {핵심 포인트 2}
- {핵심 포인트 3}
(3~5개. 문서 목차 나열 금지 — 실제 내용 요약)

## 모르면 이런 일이 생긴다

{실제 발생 가능한 버그 또는 이 프로젝트에서 실제 발생한 사례.
커밋/이슈 링크 포함.}

## 관련 코드

{연관된 파일 경로나 커밋 — 없으면 생략}
```

### 5. 완료 리포트

```
✅ 저장 완료
   파일: learned/{파일명}.md
   PR: {URL}
   현재 브랜치: {원래 브랜치}로 복귀 완료
```

---

## 제약

- 커밋: `learned/{파일명}.md` + `learned/INDEX.md` 두 파일만
- PR base: 항상 dev
- 브랜치명: `learn/` 접두사 필수
- INDEX.md: 한 줄 추가 — `- [{파일명}]({파일명}.md) — {한 줄 요약}`
- 원래 브랜치 복귀: PR 오픈 직후 무조건
- GH 인증: 세션 컨텍스트(CLAUDE.md 또는 환경변수)에서 찾아 쓴다
